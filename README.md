## ✨ Key Architectural Features

### 🎬 1. Cinematic Loading & Navigation Transition System
* **First Website Entry (7-Second Cinematic Sequence):**
  * `0.0s – 1.0s`: Pure black screen, film grain, drifting canvas dust particles, and animated blueprint grid reticles with studio coordinates.
  * `1.0s – 2.0s`: `HHA` vector monogram emergence with SVG electric stroke animations (`animate-stroke-draw`) and particle convergence.
  * `2.0s – 3.0s`: `HHA` transforms into `HARI HARAN A` through kinetic separation and glowing chromatic aberration.
  * `3.0s – 4.0s`: Kinetic typography transition into `GRAPHIC DESIGNER`, followed by cascading role badges (`VISUAL DESIGNER`, `VIDEO EDITOR`, `CREATIVE TECHNOLOGIST`).
  * `4.0s – 5.0s`: Creative workflow pipeline: `IDEA → DESIGN → EDIT → MOTION → EXPERIENCE`.
  * `5.0s – 6.0s`: `LOADING CREATIVE SYSTEM...` + real-time animated numeric progress indicator (`00% → 100%`).
  * `6.0s – 7.0s`: Final statement `WELCOME TO MY CREATIVE WORLD` followed by iris/polygon shutter clip-path, blur reduction, and light sweep revealing the homepage.
* **Internal Navigation (4-Second Cinematic Sequence):**
  * Step 1 (`0.0s – 1.0s`): Page exit distortion with zero flash.
  * Step 2 (`1.0s – 2.0s`): Fast kinetic mark sequence `HHA → DESIGN → CREATE → MOVE`.
  * Step 3 (`2.0s – 3.0s`): Destination HUD identifier readout (`LOADING / [TARGET]`).
  * Step 4 (`3.0s – 4.0s`): Shutter aperture expansion revealing destination.
* **Sound Engine:** Native Web Audio API procedural sound engine ([`soundFx.ts`](./src/lib/soundFx.ts)) with whooshes, digital ticks, and sweep effects (audio toggleable).

## 💻 Local Setup & Development

```bash
# 1. Clone repository
git clone https://github.com/Hari-Haran-A-07/www.hariharan-graphic.com.git
cd www.hariharan-graphic.com

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build
npm run preview
```
